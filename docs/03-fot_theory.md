# Frenet Optimal Trajectory (FOT) 이론

> MORAI 고속도로 대회 planning 알고리즘으로 채택. 구현 전 이론 정리.
> 원조: Werling et al., *Optimal trajectory generation for dynamic street scenarios in a Frenét Frame* (2010).

---

## 0. 한 장 직관

> **"경로 위를 s(전진)로 가면서 옆으로 d(횡)만큼 비켜야 한다. s와 d를 각각 '시간의 부드러운 곡선'으로 그리고, 여러 후보를 그려본 뒤 가장 싸고 안전한 걸 고른다. 매 주기 다시 그린다."**

1. **분리**: 2D 주행을 종방향 `s(t)` + 횡방향 `d(t)` 로 쪼갬
2. **다항식**: 각각을 부드러움이 수학적으로 최적인 다항식으로 생성
3. **샘플+선택**: 여러 후보 → 비용 최소 + 충돌 없는 것 선택 → 매 주기 반복

---

## 1. Frenet 좌표 (s, d)

기준경로(global path)를 기준선으로:
- **s** = 경로 따라 전진한 거리 (호 길이)
- **d** = 경로에서 옆으로 벗어난 거리 (좌 +, 우 −)

```
        d>0 (왼쪽)
          ↑
  ────────●────────────  기준경로 (d=0)
          │  s→ (전진)
        d<0 (오른쪽)
```
차선변경 = d를 0→3.5로. 회피 = d를 잠깐 옆으로.

---

## 2. 핵심 아이디어: 횡/종을 시간의 다항식으로

- **d(t)**: 시간에 따른 횡 위치
- **s(t)**: 시간에 따른 종 위치

둘을 합쳐 매 시각 (s,d)→Cartesian(x,y) 궤적 생성.

---

## 3. 횡방향 d(t) : 5차 다항식 (quintic)

경계조건:

| 시점 | 조건 |
|---|---|
| t=0 | d(0)=현재 횡위치, d'(0)=현재 횡속도, d''(0)=현재 횡가속도 |
| t=T | d(T)=목표 offset, d'(T)=0, d''(T)=0 (경로에 나란히 안착) |

조건 6개 → 5차 다항식 `d(t)=a₀+a₁t+…+a₅t⁵`.

**왜 5차가 최적**: jerk 제곱적분 `∫(d''')²dt` (승차감·타이어 한계)을 최소화하는 두 상태 연결곡선이 정확히 5차 다항식 (Werling 증명). = 가장 부드러운 횡 이동. 6개 조건 연립 → 계수 딱 떨어짐.

---

## 4. 종방향 s(t) : 4차/5차 (두 모드)

**모드 A — 속도 유지 (평상시)**
- 목표: 최종위치 무관, 목표속도로 순항
- t=T: s'(T)=목표속도, s''(T)=0 (s(T) 안 잡음)
- 조건 5개 → **4차(quartic)**

**모드 B — 정지/추종 (앞차·정지선·보행자)**
- 목표: 특정 지점에 정지 / 앞차 뒤 붙기
- t=T에 s(T)=목표지점 추가 → 조건 6개 → **5차(quintic)**

> 보행자 급정지 = 모드 B로 "앞에 정지"하는 s(t) → 급감속 궤적. 별도 로직 아니라 같은 프레임워크 안에서 처리.

---

## 5. 후보 생성 (샘플링)

변수를 격자로 훑어 후보 대량 생성:
- 횡 목표 offset `d1`: 예) −4m~+4m, 0.5m 간격
- 도착 시간 `T`: 예) 1s, 2s, 3s...
- 종 목표 속도(모드 A) 또는 목표 위치(모드 B)

→ (d1 × T × 속도) 조합마다 (d(t), s(t)) 궤적 하나 = 수십~수백 후보.

---

## 6. 비용 함수 (작을수록 좋음)

**횡**: `Jd = k_j·∫(d''')²dt + k_t·T + k_d·d(T)²`
- jerk(덜컹임) + 시간 + 기준경로 이탈(중앙 선호)

**종**: `Js = k_j·∫(s''')²dt + k_t·T + k_s·(s'(T)−목표속도)²`
- jerk + 시간 + 목표속도 오차

**총**: `C = k_lat·Jd + k_lon·Js`

> "빠른 완주=점수"는 `k_t`(시간)·속도항 가중치로 조절. 랩타임 튜닝 포인트.

---

## 7. 제약 & 충돌 검사 (실현가능한 후보만)

하나라도 위반하면 후보 탈락:
- **동역학**: 최대속도, 최대가속도, 최대 곡률(조향 한계)
- **충돌**: 궤적의 매 시각 점이 장애물과 안전거리 확보

**동적 장애물 처리 (FOT의 강점)**:
후보 궤적은 시간축이 있으니, 시각 t에서
- 내 위치 = 궤적의 t 지점
- 장애물 미래위치 = 현재위치 + 속도×t  (← perception이 Kalman으로 준 속도)
- 거리 ≥ 안전반경 검사

→ "1초 뒤 저 차가 여기 올 테니 이 궤적 위험"을 판단. lattice는 불가.

---

## 8. 선택 → 변환 → 재계획

1. **선택**: 제약 통과 후보 중 비용 최소
2. **변환**: (s,d) 궤적 → Cartesian(x,y,heading,속도) → control팀에 전달
3. **재계획(receding horizon)**: 다음 주기(10~20Hz) 현재상태+최신 장애물로 처음부터 다시

---

## 9. 대회 요구 → FOT 매핑

| 요구 | FOT에서 |
|---|---|
| 정적 장애물 회피 | 횡 offset 후보 중 충돌 없는 것 선택 |
| 움직이는 차 | 시간축 충돌검사(속도 예측)로 회피/추종 |
| 보행자 급출현 | 모드 B(정지 s(t)) 급감속 궤적 |
| 빠른 완주 | 종 비용 시간·속도 가중치로 공격적 주행 |
| 부드러움 | quintic/quartic = jerk 최소 (수학적 보장) |

---

## 10. 요약

**"횡=5차, 종=4차/5차, 여러 개 그려서 비용최소+충돌없는 것 선택, 매 주기 반복."**

**구현 시 필요한 것**: Cartesian↔Frenet 변환, 다항식 계수 풀이(행렬), 후보 루프, 비용/충돌 검사, 최적 선택, 재계획 루프.
